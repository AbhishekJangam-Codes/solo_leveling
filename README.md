# PulseTrack

Personal Goal & Habit Tracking web app. Create goals across Diet, Exercise, To-Do, and Cleaning & Hygiene, track daily completion, and analyze performance with data-driven insights.

## Features

- Dashboard with completion %, streaks, category progress, and quick actions
- Goal CRUD with priorities, frequencies, and quantitative targets
- Calendar with daily completion status (never overwrites history)
- Analytics: trends, category/priority performance, streaks, consistency
- Admin user management with per-user data isolation
- Light / dark mode, responsive sidebar layout

## Deploy on Vercel

1. Import this repository in [Vercel](https://vercel.com)
2. Framework preset: **Vite**
3. Build command: `npm run build`
4. Output directory: `dist`
5. Deploy

## Local development (optional)

```bash
npm install
npm run dev
```
